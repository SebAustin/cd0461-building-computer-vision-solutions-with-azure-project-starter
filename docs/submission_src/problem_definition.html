Automated Passenger Boarding Kiosk

Problem definition, data sources and solution strategy

Problem

At the gate, an agent checks every passenger by hand: does the name on the ID match the boarding pass and the flight manifest, is the date of birth right, is this the person in the ID photo, and is the boarding pass for this flight, seat and time? It is slow, inconsistent between agents, and produces no record of what was checked. The airline also gets no structured feedback on how passengers experienced boarding.

The goal is a self-service kiosk that performs these checks automatically from the documents and a short video the passenger already provides, shows a clear message (board, or see an agent and why), and records every result against the flight manifest. A separate luggage check flags prohibited items (lighters) in carry-on luggage.

The kiosk looks the passenger up on the manifest by the ticket number on the boarding pass (not by name), runs the five validations, writes TRUE/FALSE into the manifest and chooses the kiosk message.

Data validation, metrics and thresholds

ValidationRuleMetric / threshold
Name (3-way)Boarding pass name and ID name both match the manifest; case, punctuation and middle initials ignored (first given name + last surname word)Exact after normalization; extraction confidence logged
Date of birthID date equals manifest date as a calendar dateExact
Boarding passFlight number (carrier + number), seat, class, origin, destination, date, boarding time all equal the manifestExact after normalization; model's estimated field accuracy ≥ 0.95 on training
PersonID face matches the face in the videoFace confidence ≥ 0.65
LuggageNo lighter in the luggage scanMax lighter probability < 0.5; model precision must be ≥ 75%

Unreadable evidence (a field the model could not read, an unparseable date) makes the validation fail. It is never skipped. Message order: a boarding-pass failure is shown first, then an ID failure (name/DoB). Otherwise the passenger is welcomed with flight, time, route and seat, followed by one luggage sentence and one identity sentence. A passenger whose luggage was not scanned is not told a lighter was found.

Passenger feedback (emotions and sentiment from the video) is stored as a positive/negative/neutral label with each passenger's result. It is informational and does not affect boarding.
